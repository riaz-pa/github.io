# Healthcare ITSM Analytics & SLA Performance Dashboard

## Project Overview

Developed Power BI analytics solutions for Hamad Medical Corporation (HMC), supporting healthcare IT Service Management (ITSM) through operational dashboards, SLA monitoring, and service performance analysis.

The solution transformed ITSM data into meaningful insights to help service owners monitor incidents, evaluate service-level compliance, and analyze ticket lifecycle performance across healthcare IT operations.

## Business Objectives

- Monitor SLA compliance against defined service targets.
- Analyze incident volumes, ticket backlogs, and aging trends.
- Evaluate response and resolution performance across priority levels.
- Support service owners with operational KPIs and performance reporting.
- Enable historical analysis of ITSM performance through structured semantic models.

## Technical Implementation

### Data Modeling & Semantic Models
- Designed and developed Power BI semantic models for ITSM reporting.
- Implemented a star-schema data model using fact and dimension tables.
- Defined table relationships to support accurate filtering and analytical reporting.
- Structured data models to support reusable measures and scalable reporting.

### DAX & Power BI Development
- Developed DAX measures for SLA compliance, ticket volumes, backlog analysis, and service performance KPIs.
- Created calculated columns and calculated tables where required by the analytical model.
- Implemented business logic to support ticket lifecycle and operational performance analysis.
- Developed interactive dashboards with KPI cards, trend analysis, and drill-down capabilities.

### Data Transformation & Reporting
- Used Power Query for data preparation and transformation.
- Developed reporting logic to analyze incident history and ticket status.
- Supported recurring operational reporting and performance monitoring.

## Key Analytical Areas

- SLA Compliance and Breach Analysis
- Incident Management
- Ticket Aging and Backlog Monitoring
- Response and Resolution Time
- Priority-Based Performance Analysis
- Historical Service Performance Trends

## Tools & Technologies

Power BI | DAX | Power Query | Semantic Modeling | Star Schema | Data Relationships | ITSM Analytics | SLA Reporting

## Project Outcomes

- Improved visibility into healthcare IT service performance.
- Enabled structured monitoring of SLA targets and operational KPIs.
- Provided service owners with analytical views of incident and backlog trends.
- Established a reusable semantic modeling foundation for ITSM reporting.
